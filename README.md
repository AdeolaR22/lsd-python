# Python Data Structures and Algorithms Exercises

## About This Project

This project contains a collection of beginner-friendly Python programming exercises designed to improve my understanding of Python data structures, built-in functions, and fundamental programming concepts.

The exercises focus on solving practical problems using lists, tuples, dictionaries, sets, loops, and sorting techniques.

## Exercises

### Question 1: Multiply All Items in a List
Write a Python program that multiplies all the numbers in a list.

**Example:**
```python
numbers = [2, 3, 6]
```
**Output:**
```text
36
```

### Question 2: Sort Tuples by Their Last Element
Write a Python program that sorts a list of tuples in increasing order based on the last element of each tuple.

**Example:**
```python
[(2, 5), (1, 2), (4, 4), (2, 3), (2, 1)]
```
**Output:**
```python
[(2, 1), (1, 2), (2, 3), (4, 4), (2, 5)]
```

### Question 3: Combine Two Dictionaries
Write a Python program that combines two dictionaries by adding values for common keys.

### Question 4: Generate a Dictionary of Squares
Write a Python program that generates a dictionary containing numbers and their squares from 1 to a given number.

### Question 5: Sort Tuples by Float Values
Write a Python program that sorts a list of tuples according to their floating-point values in descending order.

### Question 6: Create and Manipulate Sets
Write Python programs to:
- Create a set.
- Iterate over a set.
- Add members to a set.
- Remove items from a set.
